## Как работать с репозиторием

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/<ваш-username>/algorithms-seminar-<фамилия>.git
   cd algorithms-seminar-<фамилия>
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Реализуйте функции** в папке `seminarN/tasks/`, уберите `# TODO`.

4. **Запустите тесты:**
   ```bash
   # Все тесты
   pytest seminar*/tests/ -v

   # Конкретный семинар
   pytest seminar1/tests/ -v

   # Конкретный тест
   pytest seminar1/tests/test_task1_duplicates.py -v
   ```
